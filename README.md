# RoYgBv links

The public pages behind RoYgBv's share links, served by GitHub Pages at
https://ethangottlieb.github.io/roygbv/.

- `play/` opens a puzzle shared from the game's level editor: `play/?p=CODE` hands the
  code to the game (`roygbv://play?p=CODE`), or offers the App Store and Google Play.
- `index.html` is a plain page with the store links.

Every installed build links to `play/`, so keep that address working. The source of
truth for `play/index.html` is `Tools/ShareLink` in the game repository; copy changes here.
